Systolic Array Accelerator (Ongoing)

4x4 Systolic Array in Verilog for 16-bit fixed-point Matrix-Matrix Multiplication (MMM). Hardware architecture with four independent memory blocks for dual-input data, instructions, and result storage. Instruction-based execution of 4x4*4x4, 8x4*4x8, and 16x4*4x16 matrix operations via a central FSM controller. Full systolic propagation of both input and output data without large multiplexers for processing element selection. Self-contained design with zero external data transfers during runtime. System-level Verilog testbench for automated memory initialization, pulse-driven execution control, and file-based result comparison. Python/MATLAB test-vector generation with fixed-point representation. Power, Performance, and Area (PPA) evaluation.

4R/2W Register File UVM Verification

SystemVerilog UVM testbench for 6-port (4R/2W) RISC-V register file design verification on a superscalar RISC-V processor approaching tapeout. Constrained-random stimulus and SystemVerilog Assertions (SVA) for verification of basic read/write, write-enable, and synchronous active-low reset functionality. Comprehensive test cases for WAW (Write-After-Write) hazards with Port 0 priority and RAW (Read-After-Write) scenarios during simultaneous access. 100% functional coverage achievement via Cadence Xcelium and IMC in accordance with rigorous test plans and architectural specifications.
